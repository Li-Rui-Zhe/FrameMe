FrameMe 3.0 - Image & Animation Workspace
=========================================

A general-purpose image and animation asset workbench.

Quick start:
1. Install Python 3.10+.
2. Double-click install.bat (first run only).
3. Double-click start.bat.
4. Open http://127.0.0.1:7860.

Features:
- Horizontal, vertical and grid sprite splitting
- Draggable and precise crop boundaries
- Solid-color background removal and color picking
- Consistent canvas size and subject alignment
- Batch PNG conversion and sequential naming
- Animation and frame previews
- ZIP, transparent PNG, sprite sheet and GIF exports
- Light/dark themes and mobile layouts
- Permanent local workspace and result storage
- Task size display, confirmed single/batch deletion, and explicit cross-workspace recovery

The original assets directory and command-line script are preserved.
See README.md for Chinese instructions, API details and deployment notes.
