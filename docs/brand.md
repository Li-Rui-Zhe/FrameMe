# 帧的么 · FrameMe

中文名：**帧的么**；英文名：**FrameMe**。产品围绕 GIF 表情包、免费纯色去背景和 PNG 逐帧动画素材展开，也服务于游戏、贴纸、插画、图标与产品动效制作。

主宣传语：**一张图，连成一个完整动作。**

解释文案：Prompt 让生图工具把同一角色的六个连续动作画在一张长条图里，FrameMe 再把它切成六张 PNG，去底并按顺序播放，导出 GIF 或 PNG 逐帧素材。品牌辅助文案：**为下一次创作，准备好每一帧。**

标志用三张错位的画布和一颗小星组成。它是原生 SVG，可直接随项目分发，不依赖图片生成或第三方字体。

| 颜色 | 用途 |
| --- | --- |
| 深海蓝 `#18243d` | 导航与品牌背景 |
| 创作蓝 `#4364ed` | 主要操作、选中状态与进度 |
| 纸白 `#f4f6fa` | 页面背景 |
| 薄荷绿 `#b4e2cc` | 品牌插画与素材空间意象 |
| 深绿 `#16745f` | 保存成功、步骤完成与辅助标签 |

入口 `/` 和 `/editor` 直接显示工作台，空状态以上传为主，示例由用户主动试用。工作台以预览画布为中心，基础设置常显，高级设置默认收起；背景移除提供原生画笔修补，支持恢复、撤销和缩放。浅色适合日间整理，深色适合长时间预览；两种主题均保留清晰的文字和控件边界。

“项目介绍”位于侧栏工具列表的第一项，独立地址为 `/about`，沿用工作台侧栏、字号和配色。介绍功能时提供对应工具入口，区分真实项目能力与示例素材来源；“Prompt 示例”位于“批量命名”下方，手机将五个导航项以图标加文字排列。

内部的历史键、Cookie 名称与 SQLite 作用域保留兼容格式，品牌更新不会迁移或清空现有工作区。
