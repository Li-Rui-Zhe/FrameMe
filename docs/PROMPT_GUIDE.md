# 从 Prompt 到 GIF / PNG 动画素材

运行帧的么后打开 http://127.0.0.1:7860/prompts ，或点击“批量命名”下面的“Prompt 示例”。

## 选一个示例

| 示例 | 默认输出 | 适用方向 |
| --- | --- | --- |
| Q 版角色 | 一张六帧横向长条 | 圆润、轻微 3D 光泽的表情与角色动画 |
| 写实 / 国风角色 | 一张六帧横向长条 | 需要固定服装、头发和武器的角色 |
| 娜塔莎 · 打哈欠 | 一张六帧横向长条 | 作者完整案例，可直接复制 |

整理自作者的《动作帧模板q版》《动作帧模板写实》《娜塔莎具体动作帧prompt》。保留角色一致性、全身、六帧、底部锚点、纯色背景与干净边缘约束，补充六帧连续动作节奏。原始笔记没有修改。默认 Q 版角色使用便于理解的白蓝机器人描述；换成自己的角色时需修改外观并提供对应参考图。

宣传语：**一张图，连成一个完整动作。** 默认三组模板均输出一张六帧长条，独立图片模式可在详情中切换。生图时保存的是 **1 张图片**，其中从左到右包含同一角色的 **6 个连续动作瞬间**；FrameMe 将它等分成 **6 张 PNG**，按顺序循环播放后就组成 GIF。普通单张角色立绘先用作生图工具的参考图，由该工具生成六帧动作长条，再回工作台处理。

## 复制与生图

1. 页面顶部先看三步使用指南，再选择示例并直接复制。需要修改时点击“查看 Prompt 详情与编辑”，展开角色外观、动作主题、六帧节奏、输出形式与完整文字；完整指南也按需展开。
2. 点击“复制完整 Prompt”，粘贴到你使用的生图工具，**同时上传角色参考图**。复制的文字不包含参考图片。
3. 不能自动复制时点击“选中全文”，按 Ctrl / ⌘ + C。
4. 保存生成的原尺寸图片，检查六帧数量、角色一致性、完整全身和纯色背景。模型不一定严格执行 Prompt；错误帧应重生成。

帧的么不调用生图 API。生图能力、是否支持多图与费用由所用工具决定。若不能一次输出六张独立图片，可使用同一参考图逐帧生成，或改选长条模式。

## 一张长条 → GIF / PNG 逐帧

1. 长条目标 3072 × 512，六格等宽；实际尺寸有差异时，仍需检查是否能正确等分。
2. 点击“已生成长条，去切帧与去底”，上传长条。
3. 下一次上传自动应用横向六帧、#33ff00 去底、512 px 画布、4 FPS。现有素材与结果在上传前保留；已有上传列表会保留，请按需先移除旧图。配方只应用一次，刷新后仍能等待下一次上传。
4. 检查切割线后点击“生成动画帧”。在导出区选 GIF 直接下载，或选 PNG 逐帧图片 ZIP 保存透明帧。
5. 背景有溢出或边缘残色时，请逐步调大颜色容差，每次重新处理后检查预览。不要一次调得太大，以免误删主体颜色，严重时可能导致整张图片透明；发现误删请调低容差后重试。细小彩边可配合“边缘净化 / 柔化”调整，局部残留可手动修补。需要画笔修补时，可先在“背景移除”处理原图，保存透明 PNG，再上传到序列帧切割。

## 六张独立图片 → PNG 序列

1. 模板选择“六张独立图片”，点击“已生成六张图，去除背景”。
2. 上传六张图片，下一次上传自动应用 #33ff00 去底，保留每张原图尺寸，直接打包下载处理后的透明 PNG。
3. 处理后逐张检查，需要时使用“手动修补”，擦除残留或恢复误删内容。
4. 下载并解压 ZIP。要统一成连续编号，将透明 PNG 按动作顺序上传到“批量命名”，填写动作前缀。

独立图片不会在批量命名中合成 GIF。想在帧的么制作 GIF，请使用长条路线。不同工具分别保存素材，下一步需要重新上传要处理的 PNG。

## 用到开源项目里

- [帧的么源码](https://github.com/Li-Rui-Zhe/FrameMe)：当前素材处理工作台。
- [BytePet 与资源包说明](https://github.com/Li-Rui-Zhe/BytePet#自定义角色资源包)：支持 PNG 序列帧角色资源。项目中的真实示例来自它的原始素材。

以打哈欠为例，将帧命名为 `yawn_0001.png` 至 `yawn_0006.png`，放在 `yawn/` 目录。按 BytePet 当前 README 要求补齐其余动作，准备完整角色资源包后再导入并检查动作。一个动作的 ZIP 不是完整皮肤包。

可在页面点击“先用真实 BytePet 素材跑一遍”，直接体验工作台示例；这不会自动安装 BytePet。

## 常见问题

- 角色有绿色：在生图 Prompt 和工作台里都换成与角色不重叠的纯色，避免误删。
- 复杂照片：自动去底针对纯色背景，复杂部分用手动画笔修补；没有 AI 场景分割。
- 尺寸或位置漂移：在生成阶段先固定参考图和构图，再用统一画布与主体对齐处理轻微偏差。
- 半透明细节：用 PNG 保留；GIF 仅支持全透明或不透明。

## 本地验收

安装好本机 Playwright 并设置 `FRAMELAB_PLAYWRIGHT`、`FRAMELAB_BROWSER_PATH` 后，在项目根目录运行：

```powershell
python tests/generate_prompt_fixtures.py
node tests/browser_prompts.cjs
python tests/verify_prompt_artifacts.py
```

测试素材由仓库中 BytePet 原始透明 PNG 叠加纯绿背景而成，用于复验长条与独立图两条素材处理路线。不会调用生图服务，也不会操作真实 BytePet 安装或导入。
