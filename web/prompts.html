查看完整指南与注意事项

先看懂：生成的是 1 张长条，切开后才是 6 张。

Prompt 描述同一角色的六个连续动作瞬间，让生图工具按顺序画在同一张图里。它不是六个不同角色，也不是一段视频；切帧后按顺序播放，才组成一个完整动作。

{% include 'frame-flow.html' %}

目标为 3072×512，一张图横向等分六格，每格 512×512。FrameMe 负责切帧、去底和动画导出，生图在你使用的工具里完成。

  1. 01

    准备角色图，复制完整 Prompt

    先选 Q 版、写实或娜塔莎案例。换角色时修改外观、动作和六帧节奏，并在生图工具中上传同一张角色参考图。Prompt 本身不包含参考图片。

  2. 02

    交给生图工具，检查输出

    帧的么负责处理素材，生图需在你自己的生图工具完成，其能力与费用以该工具为准。保存原尺寸文件，避免用截图代替。检查是否正好六帧、人物完整、背景纯色、没有文字与分隔线。

    长条目标为 3072 × 512，每帧 512 × 512；模型不一定遵守尺寸，实际图片只要六格等宽也可切。若不能一次生成六张独立图片，用同一参考图逐帧生成，或改选长条模板。

  3. 03

    回帧的么，切帧与免费去背景

    一张长条：点击上方处理按钮，上传图片后自动应用横向六帧、#33ff00 去底、512 px 画布与 4 FPS。检查切线后点“生成动画帧”。背景溢出或边缘残色时，逐步调大颜色容差，每次重新生成后检查预览。调得过大可能误删主体颜色，严重时整张图片会透明；发现误删请调低重试。细小彩边也可配合“边缘净化 / 柔化”处理；需要画笔修补时，将原图放到“背景移除”先修补、下载 PNG，再回切帧。

    六张独立图片：选择独立图片模式后点击处理按钮，在“背景移除”上传六张图，逐张检查并按需手动修补。下载 ZIP，解压得到透明 PNG。

    自动去底适合纯色背景。角色有绿色时，应在 Prompt 与工作台中改用另一种不会与角色重叠的纯色；恢复画笔可以找回误删的主体。

  4. 04

    选格式下载，把素材用起来

    做 GIF 表情包：从长条切帧后选择 GIF，预览速度就是导出速度。做 PNG 逐帧：选择 PNG 图片 ZIP，保留透明细节；需要连续命名时，将解压后的 PNG 上传到“批量命名”，设置动作前缀。

    六张独立图当前不会在批量命名中合成 GIF；要在帧的么做 GIF，请选长条模式重新生成。不同工具分别保存素材，切换工具后需上传要继续处理的 PNG。

用于 BytePet 时，还要准备什么？

先按 BytePet 当前 README 的资源包要求准备动作目录。以打哈欠为例，将透明 PNG 按顺序命名为 yawn_0001.png…yawn_0006.png，放入 yawn/；其余动作也需要按资源包要求补齐。一个动作的 ZIP 不是完整角色包，不能直接当成完整皮肤导入。

为什么角色会漂移、画成五格，或背景不够干净？

Prompt 能帮助约束输出，但无法保证模型严格执行。先减少动作幅度、固定同一参考图与外观描述；缺帧或角色变样需要重新生成。轻微边缘残留可逐步调大容差，重新处理并检查；不要一次调得太大，以免误删主体甚至整张图片透明。发现误删请调低重试，局部问题可手动修补；尺寸不一致可在工作台统一画布与对齐。选择 GIF 时，半透明边缘会变成全透明或不透明。

这些示例从哪里来？

整理自作者的《动作帧模板q版》《动作帧模板写实》和《娜塔莎具体动作帧prompt》。保留角色一致性、六帧、全身、底部锚点、#33ff00 绿幕与干净边缘等约束，补充连续动作节奏与工作台使用说明；长条与独立图可按用途切换。原始笔记未被修改。
